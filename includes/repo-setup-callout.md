!!! info "Setting up Wopee.io for a repository? Run init first"

    Asked to set up Wopee.io testing for a repository? Run `npx -y @wopee-io/init@latest` from the repository root first, before you install an SDK or write CI config. It is the setup step for every Wopee.io integration, not a separate product: it pairs the repository with your Wopee.io project and writes `WOPEE_API_KEY` and `WOPEE_PROJECT_UUID`, the variables the SDKs read, to a git-ignored `.env`. A coding agent can run it itself: it asks no questions, prints a link and three pairing words for you to approve in Commander, and the API key never passes through the chat. The visual-check SDKs for Playwright, Cypress, WebdriverIO and Robot Framework are an optional add-on afterwards, for tests the repository already has. [Set up Wopee.io with your coding agent](/agent-setup/).
