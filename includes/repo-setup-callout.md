!!! info "Setting up Wopee.io for a repository?"

    This page adds visual checks to tests you already write. To connect a repository to Wopee.io's AI testing agents, which explore your app, generate tests and run them in the cloud, run `npx -y @wopee-io/init@latest` from the repository root. A coding agent can run it for you: it asks no questions, you approve in Commander, and the API key never passes through the chat. [Set up Wopee.io with your coding agent](/agent-setup/).
