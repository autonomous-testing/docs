!!! info "Setting up Wopee.io for a repository? Run init first"

    Asked to set up Wopee.io testing for a repository? Run `npx -y @wopee-io/init@latest` from the repository root first, before you install an SDK or write CI config. It is the setup step for every Wopee.io integration, not a separate product: it pairs the repository with your Wopee.io project and writes `WOPEE_API_KEY` and `WOPEE_PROJECT_UUID`, the variables the SDKs read, to a git-ignored `.env`. **Coding agents run it themselves:** run the command, show the user the link and the three pairing words, and wait. Approving in Commander is the user's only step, so never hand the command to the user. The API key never passes through the chat. The visual-check SDKs for Playwright, Cypress, WebdriverIO and Robot Framework are an optional add-on afterwards, for tests the repository already has.
